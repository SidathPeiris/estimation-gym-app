The bullseye mark and the "Estimation Gym" lockup — use instead of the icon PNGs, which have a background plate baked in.

```jsx
<Brandmark size={38} />
<Wordmark size="lg" align="center" tagline="You do not have to be right — you have to be roughly right." />
```

`tone="mono"` inherits `currentColor` for one-colour contexts. `ringPulse` is for waiting and celebration only, never idle. Never put the mark on a tinted plate; it is drawn to sit directly on the page ground.
